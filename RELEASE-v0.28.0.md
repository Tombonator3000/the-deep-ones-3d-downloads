# The Deep Ones 0.28 — Deep Light

Public playtest for Windows and Linux (64-bit).

- Underwater light now varies with the water and depth, with light shafts, a reflective surface seen from below, and revised night lighting.
- Fishing line hangs in a smooth curve; hooked fish, bottom finds and an empty hook return toward the boat.
- Fuller waters include 16 additional species, bringing the field book to 43 species over three index pages.
- Illustrated depth, tension and Anchoring instruments replace the plain HUD. Large-text tip buttons have also been corrected during PC verification.
- The eight waters, expedition, story, music, environmental audio and version-8 saves remain available.

Extract the complete platform archive and run `TheDeepOnes.exe` or `Start-Linux.sh`. No GitHub account is required. GitHub's automatic source archives contain only the public download page.

A/D rows or walks, Space fishes or inspects, E begins the Havdjupet descent, and Backspace requests an early underwater return. The in-game **How to play** menu explains the current controls.

The archives contain the compiled game, launch instructions and third-party notices. These changes add no third-party source assets. Windows execution, physical controllers, subjective temporal comfort and a full human campaign remain unverified.

## Verification

Native Linux checks covered the 43-species book, all eight waters, line and fight simulation, a two-catch trip with sale, save/Continue, and 900p/1080p HUD layouts at 100% and 150% text.

Measured at 1600x900 on Intel ARL after 30 seconds warm-up: storm 49.36 fps (p95 22.24 ms), deep walking 46.95 fps (p95 24.65 ms), and deep fighting 58.93 fps (p95 19.73 ms). Each passed the 30 fps average / 33.33 ms p95 target; none of these samples contained an interval over 50 ms. These are scoped measurements, not a whole-game or steady 60 fps guarantee.
