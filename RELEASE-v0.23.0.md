# The Deep Ones 0.23 — Grounding

Public playtest for Windows and Linux (64-bit).

- Anchoring now describes lasting connection to people, places and familiar routines; Pressure describes temporary strain during a trip.
- Unusual catches show their Anchoring cost before the keep choice. Releasing still records the species.
- Actual unusual events are recorded as a factual note and a separate interpretation.
- Six merchants can respond once to local evidence in distinct practical voices.
- Counter portraits use candid working scenes, with restrained weather and time exposure.
- Clouds, distant detail and reflections have a quieter, more consistent treatment across the eight areas.
- Permanent Deep One adaptation remains playable and preserves the campaign.

Existing saves migrate forward on load. Saves written by 0.23 require 0.23 or a later compatible version.

Download the platform archive, extract everything, and start `TheDeepOnes.exe` or `Start-Linux.sh`. No account is required. GitHub's automatic source archives contain only the public download page.

Linux scoped checks and extracted offline start/Continue passed. Windows execution, physical-controller testing and a human full-campaign playthrough remain unverified.

At 1600×900 on the tested Linux machine, active fights averaged 59.97 fps (p95 17.46 ms). The harbour/weather/journal run averaged 59.59 fps (p95 20.15 ms) with one 108 ms hitch. The known occasional harbour stall remains; this is not a stable-60-fps claim. Portraits receive a mild night tint; their baked window scenery is not dynamically relit.

These archives contain compiled runtime files, launch instructions, version information and third-party notices. Internal QA reports, authoring source, machine/profile paths and debug-only output are excluded.
